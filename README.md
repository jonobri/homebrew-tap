# homebrew-tap

Homebrew formulae for [@jonobri](https://github.com/jonobri)'s tools.

```sh
brew install jonobri/tap/dexy
```

## Formulae

- **[dexy](https://github.com/jonobri/dexy)** — keep your Mac wide awake; lid closed, on battery, no nonsense.
- **[concerto](https://github.com/jonobri/concerto)** — chop a continuous DJ set into a tagged, cover-arted album.
